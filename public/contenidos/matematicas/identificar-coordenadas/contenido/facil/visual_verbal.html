Calles y avenidas

En una ciudad, las calles y avenidas nos ayudan a ubicar lugares.

Las calles usan números y las avenidas usan nombres.

¿Cómo se organizan?

  • Calles: Van de norte a sur y usan números.
  • Avenidas: Van de este a oeste y usan nombres.
  • Para ubicar un lugar, conviene leer las dos referencias juntas.
Reto 1

Completa las direcciones

Primero toca un espacio y luego una ficha del banco para completar cada dirección.

Las fichas se pueden reutilizar. Si un espacio es de calle, solo acepta números. Si es de avenida, solo acepta nombres.

Cuadrículas simples

Una cuadrícula nos ayuda a ubicar lugares con coordenadas.

Primero se lee la letra de la columna y después el número de la fila.

Antes de empezar

  • Columnas: A, B, C, D...
  • Filas: 1, 2, 3, 4...
  • Ejemplo: B2 está en la columna B y la fila 2.
Reto 1

Lleva el robot a D4

Toca una casilla vecina para mover el robot desde A1 hasta D4.

Ruta: A1
Reto 2

Marca la fila donde está B2

Toca todas las casillas que están a la misma altura que B2. No marques ninguna que quede arriba o abajo.

Direcciones

Las cuatro direcciones principales son: Norte, Sur, Este y Oeste.

Norte = arriba, Sur = abajo, Este = derecha, Oeste = izquierda.

El robot

Un robot avanza 2 unidades por cada paso que da.

Regla: pasos × 2 = unidades.
Resuelve los dos retos usando controles de + y − para ajustar los pasos del robot.
Reto 1
