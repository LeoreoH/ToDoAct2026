Mismo denominador

Cuando dos fracciones tienen el mismo denominador, la unidad se partió igual en ambos casos. Entonces la comparación se hace mirando cuántas partes coloreadas tiene cada una.

Comparamos dos pizzas divididas en octavos

Pizza A · 3/8
La pizza A tiene 3 partes de 8 partes iguales.
Pizza B · 5/8
La pizza B tiene 5 partes de 8 partes iguales.

Selecciona la conclusión correcta

Ambas fracciones están en octavos
Si el denominador es igual, gana la fracción que toma más partes.
✅ Correcto. Como ambas están en octavos, 5/8 es mayor que 3/8.
⚠️ Revisa cuántas partes coloreadas tiene cada pizza. El denominador ya es el mismo.

Mismo numerador

Si dos fracciones tienen el mismo numerador, ambas toman el mismo número de partes. Entonces la comparación depende del tamaño de cada parte.

Las dos fracciones toman una sola parte

1/3
Cada parte es grande porque el entero se repartió en solo 3 partes.
1/5
Cada parte es más pequeña porque el entero se repartió en 5 partes.

Elige la comparación correcta

Ambas fracciones toman 1 parte
Si el numerador es igual, la fracción mayor es la que tiene partes más grandes.
✅ Muy bien. 1/3 es mayor que 1/5 porque una tercera parte ocupa más que una quinta parte.
⚠️ Observa el tamaño de cada rebanada. Ambas toman una sola parte, pero no del mismo tamaño.

Reglas de comparación

Mismo denominador

Si el entero se dividió igual, gana la fracción que toma más partes.

Mismo numerador

Si ambas toman el mismo número de partes, gana la que tiene partes más grandes.

Equivalentes

Dos fracciones equivalentes se escriben distinto, pero representan la misma cantidad.
