1. Pizzería de equivalencias

Fracción: partes usadas / partes totales. Decimal: divide. Porcentaje: misma cantidad en escala de 100.

2. Placas de cien

En una placa de 100, cada cuadrito vale 1 de 100. Si hay 68 marcados, se lee 68%, se escribe 0.68 y como fracción empieza en 68/100; luego se simplifica.

Ejemplo visual

Reto 2

Bien. 68 de 100 coincide con 68%, 0.68 y 17/25.
Revisa decimal y fracción simplificada.

3. Inspector de conversiones

Una fracción dice partes tomadas entre partes totales. Para convertirla, divide el número de arriba entre el de abajo; el decimal resultante se lee como partes de cada 100 para escribir el porcentaje.

Ejemplo visual

2/52 partes de 5
2 ÷ 50.40
0.4040 de cada 100
40%porcentaje

Reto 3

Selecciona la conversión correcta de 3/5.
Correcto. 3 ÷ 5 = 0.60, y 0.60 es 60%.
Haz la división antes de elegir.
