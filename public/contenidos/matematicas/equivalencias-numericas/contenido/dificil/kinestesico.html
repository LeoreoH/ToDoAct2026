1. Pizzería de equivalencias

Una misma porción puede escribirse como fracción, decimal y porcentaje. La fracción dice partes usadas sobre partes totales; el decimal se obtiene dividiendo; el porcentaje expresa esa cantidad como partes de cada 100.

Ejemplo distinto al reto

3/43 rebanadas usadas de 4
3 ÷ 4 = 0.75decimal de la fracción
75%equivale a 75 de cada 100

2. Placas de cien

Una placa de cien espacios permite conectar porcentaje, decimal y fracción. Por ejemplo, si una placa tiene 45 de 100 espacios marcados, se escribe 45%, también 0.45, y como fracción simplificada queda 9/20.

3. Inspector de conversiones

Para convertir una fracción a decimal, divide numerador entre denominador. Después, para escribir el porcentaje, interpreta el decimal como una cantidad de cada 100.

5. Frascos en la misma escala

8. Rescate final

Una equivalencia final solo es correcta si la fracción, el decimal y el porcentaje representan exactamente la misma cantidad. Si una escritura cambia el valor, el expediente no sirve.
