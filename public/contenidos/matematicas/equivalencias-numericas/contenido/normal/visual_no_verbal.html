2. Decimal a porcentaje

Para convertir un decimal a porcentaje, mira las dos cifras después del punto. Esas cifras indican cuántas partes hay de cada 100.

Puente visual

0.58→→58%
0.24→→24%
0.5858 centésimos
58 de 100misma cantidad
58%porcentaje

Reto 2

Observa el decimal 0.35. Elige el porcentaje con la misma cantidad de centésimos.
Correcto. 0.35 son 35 centésimos.
Mira las dos cifras después del punto.

3. Grupo equivalente

Modelo, decimal y porcentaje deben mostrar la misma cantidad.

Ejemplo visual

0.42=42%

Reto 3

Selecciona el grupo donde todo coincide.
Correcto. 75 espacios, 0.75 y 75% coinciden.
Si una parte del grupo no coincide, el grupo está mal.

5. Barras de veinte

Toda la barra vale 100%. Si tiene 20 partes iguales, repartimos 100% entre 20: cada parte vale 5%.
