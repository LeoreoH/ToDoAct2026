2. Décimos

Si una barra se divide en diez partes iguales, cada parte vale una décima. Seis partes coloreadas se escriben 0.6.

3. Centésimos

En una cuadrícula de cien, cada cuadrito vale una centésima. Para construir 0.43, se marcan cuarenta y tres cuadritos.

Ejemplos visuales

0.25

0.57

Reto 3

Exacto. Cuarenta y tres cuadritos de cien forman 0.43.
Todavía no representa 0.43. Ajusta la cantidad marcada hasta llegar a 43 cuadritos.

4. Comparar decimales

Para comparar dos decimales, mira cuál ocupa más del mismo entero. Cero punto cuarenta y cinco ocupa menos que cero punto cincuenta.

5. Recta decimal

Entre 0 y 1 también viven los decimales. Si la recta se divide en diez partes iguales, cada salto vale una décima.
