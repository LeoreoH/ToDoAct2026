1. Unidad completa

Antes de usar decimales, primero identificamos el entero. Cuando una barra está completamente llena, representa una unidad completa y se puede escribir como 1.0.

Regla visual

UnidadEl objeto completo vale 1 entero.
Modelo llenoNo debe faltar ninguna parte.
DecimalUna unidad completa se escribe 1.0.

Ejemplo: barra completa

1.0

Ejemplo: cuadrícula completa

1.0

Reto 1

Selecciona la barra que representa una unidad completa.
Correcto. La barra completa representa 1.0.
Revisa si la barra está totalmente llena. Si le falta una parte, no representa una unidad completa.

2. Décimos

Si una barra se divide en diez partes iguales, cada parte vale una décima. El primer número después del punto indica cuántas décimas se toman: 0.4 significa cuatro de diez.

Ejemplos

Cuatro décimas

0.4

Ocho décimas

0.8

Reto 2

Selecciona la barra que representa 0.6.
Correcto. 0.6 representa seis de diez partes.
Cuenta las partes coloreadas. Para 0.6 deben estar coloreadas seis de diez.

3. Centésimos

En una cuadrícula de cien, cada cuadrito vale una centésima. Un decimal con dos cifras, como 0.25, indica veinticinco partes de cien.

Ejemplos

Veinticinco centésimos

0.25

Cincuenta y siete centésimos

0.57

Reto 3

Selecciona la cuadrícula que representa 0.43.
Correcto. 0.43 representa cuarenta y tres centésimos.
Busca el modelo con cuarenta y tres cuadritos coloreados de cien.

4. Comparar decimales

Para comparar decimales, usa el mismo entero como referencia. Si dos modelos tienen cien partes, la cantidad con más partes coloreadas es mayor.

Ejemplo distinto al reto

0.30

0.70

Como 70 partes coloreadas son más que 30, entonces 0.70 es mayor que 0.30.

Reto 4

Selecciona el signo correcto para comparar 0.45 con 0.50.

0.45

?

0.50

Correcto. 0.45 es menor que 0.50.
Compara cuál modelo tiene más partes coloreadas.

5. Recta decimal

En la recta numérica, los decimales también tienen una posición. Si el tramo de 0 a 1 se divide en diez partes iguales, cada salto vale una décima.

Ejemplo

0inicio del entero
0.5mitad del entero
1entero completo

Reto 5

Toca el punto donde se encuentra 0.7. Cuenta siete saltos desde el cero.
Correcto. 0.7 está en el séptimo salto después del 0.
Cuenta los saltos desde 0. El punto de 0.7 queda después de 0.5 y antes de 1.

6. Modelos y decimales

Un decimal puede relacionarse con distintos modelos visuales: una barra completa representa 1.0, una barra de diez partes puede mostrar décimos y una cuadrícula de cien puede mostrar centésimos.
